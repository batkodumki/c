# Метод попарних порівнянь з уточненням ступеня переваги

Мінімальний застосунок для проведення експертних попарних порівнянь із підтримкою шести шкал з уточненням ступеня переваги відповідно до документів «Опись рівень» та збірників РЗОД 2011–2012.

## Запуск

1. Встановіть залежності:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустіть графічний інтерфейс однією з команд:
   ```bash
   python main.py
   # або
   python -m gui.app
   ```

## Можливості

- Введення альтернатив вручну або імпортом CSV.
- Оцінювання кожної пари альтернатив у шести шкалах (Порядкова, Цілочислова, Збалансована, Потенційна, Ма–Чжен, Донаган–Додд–МакМастер) з уніфікацією до кардинальної шкали 1.5–9.5.
- Автоматичний розрахунок ваг, показників узгодженості (λ_max, CI, CR) і рекомендацій.
- Експорт результатів у директорію `out/` (`weights.csv`, `consistency.json`, `suggestions.json`, `scale_transformations.json`).
